# xiao-esp32-car-detector

A starter project for an ESP32-S3 Sense camera that detects luxury / hypercar style vehicles using a model trained in Edge Impulse, saves a burst of JPGs to SD, and exposes a local WiFi stream.

This repository is intentionally a practical scaffold: the architecture and firmware skeleton are ready, while the actual Edge Impulse model still needs to be trained and imported.

## Project goals

- Use a Xiao ESP32-S3 Sense with the OV3660 camera at SVGA (800x600)
- Run on-device inference from a model trained in Edge Impulse
- Trigger a capture burst when confidence is above a threshold
- Save files to SD card
- Expose a local WiFi stream for live preview
- Provide a clean path to evolve toward a production outdoor setup

## Current status

This repo contains the base firmware structure and planning files to start the build.

## Hardware assumptions

- Xiao ESP32-S3 Sense
- OV3660 camera
- SD card module or onboard SD support
- Outdoor camera housing / weatherproof enclosure
- 5V power source or USB power supply

## Architecture

- `firmware/src/main.cpp`: the main state machine
- `firmware/src/config.h`: all thresholds, pins, and camera parameters
- `firmware/src/camera_manager.*`: camera initialization and frame capture
- `firmware/src/sd_manager.*`: save JPGs and logs to the SD card
- `firmware/src/edge_impulse_runner.*`: placeholder for the Edge Impulse classifier
- `docs/PLAN.md`: the build roadmap

## Quick start

### 1) Install tools

- VS Code + PlatformIO extension
- Git

### 2) Open the firmware folder in PlatformIO

```
cd firmware
pio run
```

### 3) Flash your board

```
pio run -t upload
```

### 4) Connect to the access point

- SSID: `XIAO-LUX-CAM`
- Password: `luxury123`

Then open:

- http://192.168.4.1/snapshot
- http://192.168.4.1/stream

## Important note

The model inference function is intentionally a placeholder. Replace it with the code generated by Edge Impulse for your trained model.
